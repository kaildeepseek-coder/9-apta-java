# Java Collections: List, Set және Map

## Жоба туралы

Бұл жоба Java тіліндегі коллекциялармен жұмыс істеудің негізгі
тәсілдерін көрсетеді. Бағдарламада `List`, `Set` және `Map`
интерфейстері қолданылады.

## Қолданылған технологиялар

-   Java
-   `java.util` кітапханасы
-   `ArrayList`
-   `HashSet`
-   `HashMap`

## Бағдарламаның жұмысы

### 1. List

`List` элементтерді ретімен сақтайды, индекстер арқылы алуға мүмкіндік
береді және қайталанатын элементтерге рұқсат береді.

Кодта: - `ArrayList` құрылады; - оған алма және алмұрт қосылады; -
`get(1)` арқылы екінші элемент алынады; - `remove()` арқылы элемент
өшіріледі; - `size()` арқылы элементтер саны көрсетіледі.

### 2. Set

`Set` қайталанатын элементтерді сақтамайды.

Кодта: - `HashSet` құрылады; - Алматы және Астана қалалары қосылады; -
Алматы екінші рет қосылғанымен, жиынтықта бір рет қана сақталады; -
`size()` және `contains()` әдістері қолданылады.

### 3. Map

`Map` деректерді кілт пен мән жұбы түрінде сақтайды.

Кодта: - `HashMap` құрылады; - студенттердің аттары кілт, ал бағалары
мән ретінде беріледі; - бір кілтке жаңа мән берілгенде, бұрынғы мән
жаңартылады; - `get()` арқылы мән алынады; - `entrySet()` арқылы барлық
кілт-мән жұбы экранға шығарылады.

## Іске қосу

1.  Жобаны IntelliJ IDEA, Eclipse немесе басқа Java IDE бағдарламасында
    ашыңыз.
2.  Кодты `Main.java` файлына орналастырыңыз.
3.  JDK орнатылғанын тексеріңіз.
4.  `Main` класындағы `main()` әдісін іске қосыңыз.

Командалық жол арқылы іске қосу:

``` bash
javac Main.java
java Main
```

## Күтілетін нәтиже

Бағдарлама консольге: - `List` элементтерінің тізімін, индекс бойынша
алынған элементті және тізім өлшемін; - `Set` ішіндегі қайталанбайтын
қалалар санын және қаланың бар-жоғын; - `Map` ішіндегі жаңартылған
бағаны және барлық студент-баға жұптарын шығарады.

`HashSet` және `HashMap` элементтерінің шығу реті алдын ала
кепілденбейді.

## Қорытынды

Жоба Java коллекцияларының негізгі айырмашылықтарын көрсетеді: `List`
--- реттелген және қайталанатын элементтерді сақтайды, `Set` ---
қайталанбайтын элементтерді сақтайды, ал `Map` --- кілт пен мән
арасындағы байланысты сақтайды.
