Спорттық жарысты модельдеу (Java)
Жоба туралы
Бұл бағдарлама Java тілінде көп ағынды (multithreading) спорттық жарысты
модельдейді. Жарысқа бес қатысушы қатысады. Әр қатысушы жеке ағын арқылы
жұмыс істейді, бес кезеңнен өтеді және мәреге жеткен реті ортақ тізімге
жазылады.
Қолданылған технологиялар мен ұғымдар
- Java
- Runnable интерфейсі
- Thread класы
- start() және run() әдістері
- sleep() әдісі
- join() әдісі
- ArrayList және List
- synchronized блогы
- Random класы
Бағдарламаның құрылымы
RunnerTask класы
RunnerTask класы Runnable интерфейсін іске асырады және бір
қатысушының жарыстағы әрекетін сипаттайды.
- runnerName --- қатысушының аты.
- finishOrder --- қатысушылардың мәреге жету ретін сақтайтын ортақ
  тізім.
- TOTAL_STAGES --- жарыс кезеңдерінің саны (5).
- Әр кезеңде Thread.sleep() арқылы кездейсоқ кідіріс жасалады.
- Қатысушы барлық кезеңнен өткен соң, аты finishOrder тізіміне
  қосылады.
SportsCompetition класы
SportsCompetition класы бағдарламаның негізгі орындалуын басқарады.
1. Алдымен run() әдісін тікелей шақыру көрсетіледі. Бұл жағдайда
   тапсырма жаңа ағын құрмай, main ағынында орындалады.
2. Кейін start() әдісі шақырылып, жаңа ағын іске қосылады.
3. Жарысқа бес қатысушы қосылады: Асқар, Мадина, Данияр, Айгерім және
   Ержан.
4. Әр қатысушы үшін жеке Thread құрылады және start() арқылы іске
   қосылады.
5. join() әдісі барлық қатысушы ағындарының аяқталуын күтеді.
6. Соңында мәреге жету реті консольге шығарылады.
Синхрондау
Қатысушылар бір ортақ finishOrder тізіміне жазба қосады. Бірнеше
ағынның бір уақытта тізімді өзгертуінен туындауы мүмкін мәселелерді
болдырмау үшін жазу әрекеті synchronized (finishOrder) блогында
орындалады.
Бағдарламаны іске қосу
1. IntelliJ IDEA, Eclipse немесе басқа Java IDE ашыңыз.
2. Кодты SportsCompetition.java файлына орналастырыңыз.
3. JDK орнатылғанын тексеріңіз.
4. SportsCompetition класындағы main() әдісін іске қосыңыз.
Командалық жол арқылы:
javac SportsCompetition.java
java SportsCompetition
Күтілетін нәтиже
- run() тікелей шақырылғанда, демо хабарлама main ағынының
  атауымен шығады.
- start() шақырылғанда, демо тапсырма бөлек ағынмен орындалады.
- Бес қатысушының әрқайсысы бес кезеңнен өтеді.
- Әр қатысушының кезеңдерден өту жылдамдығы кездейсоқ кідірістерге
  байланысты өзгереді.
- Қатысушылардың мәреге жету реті консольде көрсетіледі.
- Соңында барлық ағындардың жұмысы аяқталғаны туралы хабарлама шығады.
Нақты мәреге жету реті әр іске қосқанда өзгеруі мүмкін, себебі ағындар
параллель орындалады және әр кезеңдегі кідірістер кездейсоқ таңдалады.
